# PixelTrace

사진 폴더를 색인하고 문장·파일명·이미지로 검색하는 Android 로컬 앱입니다.

## 지원 환경

Android 10 이상 · arm64. GPU 지원 여부는 기기와 드라이버에 따라 다릅니다.

## 사용법

1. APK를 설치하고 설정에서 추론 엔진을 선택합니다.
2. 사진 폴더를 추가하면 선택한 폴더의 색인이 자동으로 시작됩니다.
3. 필요한 모델은 처음 사용할 때 다운로드합니다. 진행 영역의 `취소` 버튼으로 작업을 취소할 수 있습니다.
4. 문장·파일명으로 검색하거나 이미지를 선택해 비슷한 사진을 찾습니다.

이미지 상세에서 확대할 수 있으며, 설정에서 NSFW 숨김·블러를 선택할 수 있습니다.

작업 중에는 진행 알림이 유지되며 알림에서 취소할 수 있습니다. 알림 권한을 허용하면 다른 앱을 사용하는 동안에도 진행 상태를 확인할 수 있습니다.

`라이브러리 내보내기 / 가져오기`로 색인을 백업하거나 옮길 수 있습니다. 원본 사진은 하위 폴더와 파일명을 유지해 별도로 복사하고, 가져올 때 원본 폴더를 지정하세요. 같은 상대 경로에 저장된 임베딩을 연결합니다. 내보내기에는 상대 경로가 포함되며 절대 경로와 원본 사진은 포함되지 않습니다.
